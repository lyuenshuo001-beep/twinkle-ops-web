# TWINKLE OPS Web build

Unity 6000.6.5f1 / URP 17.6 / 0.2.0-alpha.

This repository contains the static browser build and locally hosted game assets.
Source project: https://github.com/lyuenshuo001-beep/twinkle-ops-unity
Asset credits: ThirdPartyNotices/CREDITS.md and credits.html.

GitHub Pages serves main / root. Build artifacts intentionally do not use Git LFS.
The same folder can be served by another static HTTPS host. Do not open index.html using file://.

Early single-player alpha. Desktop keyboard/mouse recommended; mobile touch support remains experimental.
